# 08 · 규제·개인정보·의료 경계

> 근거 리서치: [docs/research/regulatory-market.md](../research/regulatory-market.md) (2026-10-24, 법령 현행본 기준). **법률 자문이 아니다.** 실서비스 전 의료법 전문 변호사 검토가 필요하다. 해커톤 데모는 가상 병원·가상 인물만 쓰므로 실제 유치 행위가 아니다.

## 2. 고객 자격 (매칭 대상)

| 고객 유형 | 판정 | 제공 기능 |
| --- | --- | --- |
| 외국 국적 + 단기 방문 (`residency = short_term_visitor`) | 유치 대상 | 전체 (요청 정리, 매칭, 견적, 판정, 예약, 결과) |
| 외국 국적 + 국내 거주 (`residency = resident`: 외국인등록, 거소신고) | 유치 대상 아님 | 내 시술 기록, 레시피 조회까지. 매칭·예약 불가 안내 |
| 한국 국적 (`nationality = KR`) | 유치 대상 아님 | 내 시술 기록, 다음 회차 알림, 기록 공유(데이터 공급). **매칭·예약·추천 토큰·이벤트 비교 없음** (메인 기능만, 오너 결정 2026-10-24) |

구현 강제:
- 플랫폼 `platform.match_clinics`는 `visitorProfile.nationality = "KR"` 또는 `visitorProfile.residency = "resident"`면 `TASK_STATE_REJECTED` + 사유 `not_eligible_foreign_patient`.
- 병원 에이전트는 추천 토큰 없는 `clinic.quote`·`clinic.book`을 거절하므로 우회 경로가 없다.
- 단위 테스트: `tests/eligibility.test.ts` (KR 거절, resident 거절, JP·short_term 통과).

### 매칭 점수와 돈의 분리

- 병원이 낸 돈(광고·리스팅·수수료율)은 **매칭 점수와 판정에 어떤 경로로도 들어가지 않는다.** `matching.ts`는 정산 모듈을 import 하지 않는다 (경계 테스트).
- PLANNING.md 13절의 "리스팅·광고·상단 노출"은 비의료인 의료광고 리스크로 **보류** (오너 결정 2026-10-24). 수익 모델은 고시 상한 내 유치 수수료를 기본으로 검토한다.

## 4. 부가세 환급

- 외국인 관광객 미용성형 의료용역 부가세 환급 특례(조세특례제한법 제107조의3)는 **2025-12-31로 종료**, 2026-10-24 현재 연장 확정 없음 (법안 계류). https://www.hankyung.com/article/2025120320461 , https://www.law.go.kr/법령/조세특례제한법/제107조의3

### 보안 최소 요건 (P0부터)

1. 고객 에이전트 RPC·카드는 bearer 없이 401. 병원 토큰으로 고객 데이터 조회 불가 (역할 검사 테스트).
2. A2A 로그 저장 시 `safetyInfo.*`, `guest.contactHandle`, `passportName`, `contact.*` 마스킹 (`lib/a2a/mask.ts` + 테스트).
3. 고객 에이전트는 보내기 전 동의 원장을 확인하고, 병원으로 가는 `procedure-request`는 [03-a2a-protocol.md](03-a2a-protocol.md)의 필드 규칙 표에 적힌 필드만 남긴다 (`notes`, `budgetKrw`, `ageBand`, `residency` 제거).
4. 데모 시드에 실명·실연락처를 쓰지 않는다.
5. 비밀값은 `.env`만. 커밋 금지 (README 규칙).

## 6. 의료 경계 (에이전트가 하지 않는 것)

| 금지 | 대신 |
| --- | --- |
| 진단 ("이건 기미예요") | 고객이 말한 고민을 슬롯으로 기록 |
| 적응증·금기 판단 ("임신 중이니 안 돼요") | 안전 정보를 병원에 전달, "시술 가능 여부는 의사가 판단해요" |
| 시술 권유 ("리쥬란 받으세요") | 데이터 인용 ("같은 고민의 한국 20대 후반 여성 기록에서 가장 많이 받은 조합") |
| 효과 보장 ("주름이 없어져요") | 시술 마스터의 효과 시기·다운타임을 범위로, 출처 표기 |
| 사진 피부 분석 | P2까지 사진은 병원 전달용 보관만 (의료기기 해당 여부 검토 전) |

프롬프트 공통 블록 `lib/llm/prompts/medical-boundary.ts`에 위 표를 넣고, 고객 에이전트·온보딩 프롬프트가 모두 포함한다. 금지 표현 회귀 테스트: `tests/medical-boundary.test.ts` (모델 출력 샘플을 고정 픽스처로 두고 금지 패턴 검사).
